# Кино Архив — Android / Android TV

Оболочка (WebView) для https://kino.galsmedia.uz/ — один APK для телефона и ТВ-приставки.

## Как собрать APK

### Вариант 1. Android Studio
1. File → Open → выбрать папку KinoArchive, дождаться синхронизации Gradle.
2. Build → Build Bundle(s) / APK(s) → Build APK(s).
3. Готовый файл: app/build/outputs/apk/debug/app-debug.apk

### Вариант 2. Без установки Android Studio (GitHub)
1. Создайте репозиторий на github.com и загрузите туда содержимое этой папки.
2. Вкладка Actions → Build APK → Run workflow.
3. Скачайте app-debug.apk из Artifacts.

## Установка
- Телефон: скопируйте APK, откройте, разрешите «Установку из неизвестных источников».
- Приставка: положите APK на флешку или установите через «Downloader» / «Send Files to TV», откройте файл-менеджером.

## Управление
Телефон: касания, жесты, «Назад» — назад по страницам, двойное «Назад» — выход.
Пульт:
- стрелки — двигают курсор, если держать — быстрее; у края экрана страница прокручивается
- OK — клик по месту курсора
- MENU — режим «курсор» / обычная навигация по ссылкам
- Назад — назад по страницам / выход из полноэкранного видео
- Play/Pause, перемотка — управление видео; в полноэкранном видео OK = пауза, влево/вправо = ±10 сек

Адрес сайта меняется в MainActivity.java (константы HOME и HOST).
